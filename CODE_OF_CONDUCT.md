# Code of Conduct

## Our expectations

This project is a small, hobby-scale effort. Everyone interacting in this
repository — through issues, pull requests, discussions, or comments — is
expected to act with basic courtesy and respect:

- Be civil and constructive. Disagree with ideas, not people.
- Assume good faith; ask questions before assuming bad intent.
- No harassment, insults, personal attacks, or discriminatory language.
- Stay on topic and keep feedback actionable.
- Respect that this is unpaid, best-effort maintenance (see
  [SECURITY.md](SECURITY.md)) — response times may be slow or absent.

## Scope

This applies to all project spaces: issues, pull requests, discussions, and
any other communication channel directly tied to this repository.

## Enforcement

The maintainer may edit, lock, or remove content, and may block participants,
who violate these expectations. There is no formal enforcement committee or
appeals process for a project of this size — decisions are made at the
maintainer's discretion.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer
directly through a private channel, such as a GitHub direct message, rather
than a public issue.
