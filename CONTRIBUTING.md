# Contributing

Thanks for your interest in this project.

## Pull requests

This is a personally owned, hobby-scale project (see [README.md](README.md) and
[SECURITY.md](SECURITY.md)). It is **not currently accepting pull requests**.
Unsolicited PRs may be closed without review, regardless of quality — please
don't take it personally.

## Issues and feature requests

Bug reports and feature requests **are welcome**. Please open a
[GitHub issue](../../issues) and include:

- **Bug reports:** what you expected, what happened instead, steps to
  reproduce, and relevant logs/environment details (OS, Rust version, hypatia
  shelf/model configuration if relevant).
- **Feature requests:** the problem you're trying to solve and, if you have
  one, a suggested approach.

Note that most core memory behavior comes from the upstream
[MarchLiu/hypatia](https://github.com/MarchLiu/hypatia) engine — issues
specific to that functionality may need to be filed there instead. That said,
feel free to file them here too; I'm happy to receive them and help however I
can, even if the fix ultimately belongs upstream.

## Response expectations

As noted in [SECURITY.md](SECURITY.md), this project is maintained on a
best-effort basis with no committed response time.

## Code of conduct

All interactions in this repository are expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
